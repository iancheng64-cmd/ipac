# iPac 0.5.5 / Build 114

日期：2026-11-27（台北）。針對整個 macOS 共用的磁碟寫入、CPU 記憶體映射與桌面繪圖，也修正開機界面、拖曳和捲動。不改既有 VM 的解析度、CPU、RAM、磁碟配置或畫質。Mac 端測試不是 iPad 實測，也不是與原生 M1 Mac 的速度比較。

## 改了什麼

| 使用情境 | 修正與驗證 |
| --- | --- |
| 存檔與背景寫入 | 同一筆 virtio 磁碟請求的多段資料用一次向量寫入，不再每段呼叫一次；不跨請求，不更改同步、屏障或快取政策。修正了越過虛擬磁碟尾端的請求回報失敗但仍寫進前段的錯誤。M4 暖快取檔案、9 輪交錯測試：4 × 16 KiB 的單筆寫入中位數從 15.19 降到 7.64 微秒，8 × 16 KiB 從 31.18 降到 11.44 微秒。不代表 SSD 實體落盤或整體 App 快了同樣比例。 |
| macOS 開機、第一張桌面畫面出現前 | 尋找開機畫面改在背景序列佇列進行；Core Graphics 接管引擎已複製好的像素，不再多搬一次整張畫面。測試檢查執行緒、像素內容、所有權、停止與世代切換；沒有縮短或跳過客體自己的開機流程。 |
| 客體忙碌時雙指滑動、抬指或放鍵 | 舊版在 USB 佇列塞滿後會漏掉新的抬指或放鍵。重現案例中，雙指移動 180 幀且一指折返後，舊版仍回報兩指按住；新版用 11 份報告送達最終狀態，保留折返、末兩點和末段 8 ms 間隔。正常路徑的 7 份報告全部保留。極端滿載時仍不保證重播全部歷史。 |
| 實體滑鼠拖曳與捲動 | 進入畫面與啟動 VM 以前會各自註冊一輪滑鼠通知，第二次也會放開原本按住的按鍵。現在只啟動一次；速度滑桿仍即時生效，但不再每筆捲動都查偏好設定。沒有更改加速曲線。 |
| 程式載入或切換時的 CPU 工作 | 一筆範圍頁表失效操作不再對每一頁重複掃描相同的程序快取，各頁與各核心仍正確失效。也修正了範圍剛好到達最高位址時可能漏掉最後一頁的錯誤。1,849 項記憶體管理檢查通過。M4 的 128 頁／單一地址空間測試從約 1.92 降至 1.12 微秒；不是 App 啟動時間。 |
| 桌面繪圖 | Metal 在同一條序列工作佇列上重用常見命令緩衝區，最多保留 256 KiB；大命令仍獨立配置。M4 的 4 KiB 命令快照中位數從約 260 降至 129 奈秒。GPU 實際讀回、錯誤後下一指令、6 次建立與釋放及 384 次 GPU 完成均通過；未測 iPad FPS。 |
| 閒置與長時間使用 | 原生日誌改成檔案有變更時才讀；0.5 秒無資料測試有 0 次讀取回呼。最近 4,000 行用固定容量循環儲存，啟動僅回讀上一次日誌末 8 KiB。超長單行在檢視器中只保留前 64 KiB，原始檔不截短。 |
| 快照還原 | 在使用保存的輸入資料前先驗證佇列深度與報告長度，不改寫舊快照格式。測試 VM 通過開關機、錯誤快照拒絕與正常暫停／還原。 |

## 與原生 M1 比較

1. 在同一台 iPad 比對兩版時，使用同一部 VM、同一個磁碟、解析度、核心數及 RAM；冷卻到「正常」再開始。不要先改參數或清除快取。首次開啟與正常結束後再開分開記。
2. 記兩件事：在同一個 Finder 視窗拖曳和雙指捲動時有無停頓；同一款 App 從點擊到視窗出現、以及何時開始能接受操作。不要把 GPU 更新數當成螢幕實際 FPS。
3. 選用工具：在客體 macOS 或真正的 Mac 上，可從終端機執行版本資料夾的 `sh measure_app_window.sh`（原始碼：`tools/measure_app_window.sh`）。它只開「計算機」，已開啟就拒測，不關閉任何 App。以 50 ms 間隔觀測第一個一般視窗；這不代表內容已完成繪製或已可以操作，也不計入 iPad 的最後顯示延遲。首次與重開結果不要混在一起。比較原生效能須使用實際的 8 GB M1 Mac。
4. 整體操作：從同一資料夾執行 `sh measure_system.sh 30`，在這 30 秒用 Finder 複製同一份測試檔，同時切換 App、打字。記下最明顯停頓及 iPac 系統熱狀態。工具記錄計時程序每 100 ms 醒來的額外延遲（中位數、p95、最差值）和該 macOS 的整機壓縮／換頁計數差，不開其他 App、不寫檔。這是排程與記憶體線索，不是視窗延遲、實際掉幀數、iPadOS 換頁或 CPU 溫度。

[Apple 的 iPad Air 5 規格](https://support.apple.com/en-us/111887)列出 M1 與 8 GB RAM。iPac 在這台 iPad 上仍須轉譯來賓指令、轉送 GPU 命令，實體記憶體也須與 iPadOS 共用。沒有將整體體感或開 App 速度標成與原生等效。

## 升級

請先於客體 macOS 正常關機，確認沒有待恢復快照，再以原簽名身分覆蓋安裝。不要先刪除舊 App。本版發行時尚未在目標 iPad 驗收；請保留上一版 IPA。
