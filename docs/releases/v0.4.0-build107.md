# iPac 0.4.0 / Build 107

日期：2026-11-25（台北）

這是既有 GitHub 發布版本，以下依原發布說明整理，本輪沒有重新建置或實機驗收此版。

## 這版改了什麼

- 整合 GetMoreRam、StosSign 與 Anisette，支援 Apple ID、2FA 及 SideStore 帳號匯入。
- 提供記憶體權限申請，完成後仍需透過簽名工具重新 Refresh / 簽名才能生效。
- 加入 JIT 附加後的 No Footprint 分配模式，並改善 GuestMemory 重複扣除 JIT 空間的問題。
- 支援在 VM 關機後調整單機 RAM 與 CPU 核心數。
- 設定同步到 `machine.json`，並清除已不相容的續玩快照。
