# iPac 0.5.2 / Build 111

日期：2026-11-26（台北）。本機測試版，未做本版的 iPad 真機驗收。

## 本版修正

- **保住快照**：還原錯誤、設定不符或無法啟動 CPU 時不會直接刪檔並冷開機。可先改回原設定再試，或明確確認捨棄快照後冷開機。暫停後續跑失敗也會保留快照。
- **看得到關機結果**：已暫停的 VM 按電源也會要求確認，不會只關掉控制畫面。強制關機會等到磁碟同步結束，再顯示原生引擎的結果。
- **儲存與安裝**：系統磁碟或輔助儲存同步失敗，不會把暫停狀態寫成可恢復快照，也不會回報正常關機。安裝器在還原完成後會再確認停機結果；同步失敗或逾時時，保留已還原的 VM 和安裝映像供檢查。
- **小容量裝置的續傳**：容量預檢與下載器現在會辨認同一份部分下載，也支援舊檔名。清理中斷快照時只處理 VM 目錄內指定的暫存檔，不動完整快照。
- **外接安裝暫存**：安裝流程結束後才清理原來那顆磁碟上的暫存；還原工作未停止或磁碟已更換時不會清理。
- **打包**：Bitrise 使用本次建置的 IPA 重建 ZIP，不再誤取桌面舊檔。原生引擎可以從同層的 Husk 專案找到 iOS 網路標頭；擷取依賴時也會將標頭和靜態函式庫一起保留。

## 升級前

快照識別包含 App 的版本、Build 和建置資訊。**請先在舊版恢復 VM、儲存來賓 macOS 的工作並正常關機，再升級。** 新版會保留不相容的舊快照，但不能直接用它續跑；捨棄快照會失去只存在 VM 記憶體的進度。

檔名：`iPac-v0.5.2-build111.ipa`。此 IPA 為 ad-hoc 簽名，請用與舊版相同的開發 Team 重新簽署後覆蓋安裝，不要先刪 App。此版不變更既有 VM 的 RAM、CPU 或磁碟位置；不包含 macOS 安裝映像或 Boot ROM。

## 驗證範圍

已在 Mac 上測試 VM 電源循環、快照還原失敗後重試、磁碟同步失敗、安裝結尾及下載續傳；另有儲存安全、電源按鈕狀態、雙語與打包回歸。本版未在 iPad 上重跑 macOS 開機，也未做外接 SSD 實機拔線或 Bitrise 雲端建置。
