# iPac v0.6.0 (Build 119)

## 主要更新

1. **全面提升流暢度（解決 CPU 搶核、熱降頻、記憶體 SWAP 懸崖與磁碟 I/O 阻塞）**
   - **JIT 快取與主機記憶體平衡**：針對 ≤ 8 GB 裝置（如 M1 iPad Air）將 JIT 快取上限鎖定於 `512 MB`，釋放約 1.8 GB 實體記憶體給 Guest macOS 與 Metal GPU，避免執行數分鐘後觸發記憶體壓縮與 Metal 編碼暴增。
   - **P-Core 與 vCPU 排程平衡**：≤ 8 GB 裝置在開機時將 vCPU 上限自動匹配至 4 顆高效能 P-core（留下 E-core 專職 Metal 繪圖與 NVMe I/O），且主機溫度達「微溫」以上即提前協調跨核同步等待，降低多核鎖競爭；可透過 `HV_ALLOW_ALL_CPUS=1` 覆寫。
   - **磁碟 I/O 最佳化**：對虛擬磁碟啟用 `F_RDAHEAD` 預讀、在 iOS 停用會倍增主機佔用的雙重分頁快取（`F_NOCACHE`，保留讀取效能並釋放數 GB 主機快取）、將 `virtio-blk` 背景工作提升至 `QOS_CLASS_USER_INITIATED`，並於 iOS 預設開啟 `HV_SUPERBLOCKS=1` 與互動期間高速快取寫入（`HV_FLUSH=1`，暫停／關機仍完整 `fsync`）；移除執行中每 60 秒一次的預覽抓圖停頓。

2. **Apple 設計懸浮可調大小雙語鍵盤（含台灣注音 `ㄅㄆㄇ` 與中文輸入）**
   - **不縮小 macOS 顯示範圍**：懸浮鍵盤直接覆蓋浮動於畫面上方，打開、移動或縮放都不再擠壓或閃動 `BootDisplay`。
   - **自由移動與調整大小**：拖曳頂端 Grabber 把手即可任意移動位置（雙擊重置），右下角縮放手把、`A-`／`A+` 按鈕或雙指捏合皆可即時調整尺寸。
   - **台灣注音 ㄅㄆㄇ ＋ ABC 雙語切換**：內建 41 鍵 Apple 台灣鍵盤注音配置，左下角 `🌐` 同步切換注音／英文鍵帽與 Mac 輸入法（`⌃Space`），並提供 `選字 ↓` 與頂部 **`中文組字`** 列讓您直接用 iPadOS 注音／手寫送出繁體中文。
   - **保證可收起**：改用純原生無手勢衝突的收起按鈕與控制列 `zIndex` 保護，確保系統鍵盤與懸浮鍵盤隨時秒關不卡住；系統鍵盤（`Input.swift`）同步補齊中文／Unicode 直送剪貼簿貼上，並在關閉時確實釋放焦點。

## SideStore 安裝與覆蓋升級說明

- 本版維持 Bundle ID `com.henge.app`，**請勿刪除 iPad 上原有的 iPac**，以免遺失本機 macOS 虛擬機磁碟。
- 請在 SideStore 的 **My Apps** 分頁點選左上角 **`+`**，從 SideStore 本機 `Documents` 資料夾選取 `iPac-v0.6.0-build119.ipa` 進行覆蓋簽名安裝。
