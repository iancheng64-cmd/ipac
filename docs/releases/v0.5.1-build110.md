# iPac 0.5.1 / Build 110

日期：2026-11-25（台北）

狀態：測試版。此版本延續 0.5.0 的功能，聚焦真機驗收時發現的問題。

## 這版修了什麼

- **JIT 狀態誤報**：只有可執行區域通過自測後，才公布 JIT 可用狀態。自測失敗不再顯示「JIT 已開啟」，也不會誤跳過等待流程。
- **語言切換後的選單標籤**：切回繁體中文時，JIT 啟用方式的選中值會同步更新；只重建該選單，不重建整個設定頁或 VM。
- **版本一致性**：主程式與 JIT helper 同步為 `0.5.1 / 110`。
- **故障分支回歸**：新增直接使用原生 JIT 原碼的故障注入測試，涵蓋自測失敗、發布時機、正常 detach 與既有有效映射的保留。

## 建置前驗證

- 13 組核心與 App 回歸全數通過，含 JIT 中繼資料、雙語呈現、記憶體、安裝與儲存安全。
- JIT availability 故障注入測試由原版 2 項失敗轉為 5 / 5 通過。
- IPA 打包與主程式／helper 版本一致性檢查 14 項通過。
- 上述為 Mac 端結果，不代表 VM 已在 iPad 成功開機。

可單獨執行 `make test-ios-jit-availability` 重跑新增的故障分支測試。

## 安裝與資料

檔名：`iPac-v0.5.1-build110.ipa`

維持原有 App 的 Bundle ID 與簽名 Team，以覆蓋方式更新，不要先移除舊 App。公開 IPA 為 ad-hoc 簽名包，需要側載工具或合法的裝置開發簽名；它不是可直接安裝的永久簽名包。

本次不更動既有 VM 的 RAM、CPU、磁碟位置或快照格式。安裝成功、JIT 自測成功與 macOS 成功開機是不同驗收項目；真機紀錄另列，不以建置或單元測試取代。

## 尚存限制

- 不保證任意工作負載、長時間操作或所有 iPadOS 版本完全零 bug。
- 緊湊 JIT 選項壓縮的是 pointer 中繼資料，不是可執行程式碼；所有工作負載零效能影響尚未證明。
- 既有快速 flush／pause 的寫入持久性風險仍須另外處理。
- 手機 SSD 的 USB 掛載、速度、斷線與快照恢復仍需實機驗收；本版不是新的 iPhone SSD 驅動。
- 不包含 Apple macOS 安裝映像或 Boot ROM。
