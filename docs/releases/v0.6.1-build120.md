# iPac v0.6.1 (Build 120)

## 主要更新

1. **解除過度硬體降規並加入核心引擎加速（在保有全速規格下大幅提升流暢度）**
   - **完整 JIT 1 GB 容量 ＋ 緊湊中繼資料（Compact Metadata）**：≤ 8 GB M1 iPad 裝置恢復 `1024 MB`（1 GB）JIT 指令快取（避免 `512 MB` 反覆觸發全區 `stop_the_world` 清空重譯），並於 `< 10 GB` 裝置預設開啟 `HV_COMPACT_JIT_METADATA=1`，使用 32 位元索引節省約 161 MB 實體記憶體與快取占用。
   - **虛擬 CPU 與熱壓力平衡調校**：≤ 8 GB 裝置預設保留 `6` 核心（`Device.maxSafeCPUs`）供虛擬 macOS 全速排程，同時保留 2 核心給 Metal GPU 與磁碟工作；`applyHostHeat` 恢復僅在 `.serious`／`.critical` 才讓 `hv_cpu_sync` 休眠，「微溫」（`.fair`）不再人為降速。
   - **恢復主機磁碟快取（UBC）**：iOS 預設恢復標準檔案頁快取搭配 `F_RDAHEAD`（僅在顯式設定 `HV_DISK_NOCACHE=1` 時停用），避免虛擬磁碟大小寫寫入與隨身硬碟隨機讀取倒退 2–3 倍。
   - **消除同步日誌寫盤風暴（實機 `henge.log` 定位瓶頸）**：對 macOS 27 核心重複觸發的未定義指令（`0xe7ffdeff`）回溯、`S3_*_C15_*` 實作定義暫存器、未識別 HVC 與 `pvg-lite` `hvgamma` 全任務掃描加上去重／限流與預設閘控，徹底消除 vCPU 執行緒上的無緩衝同步 `write(2)` 阻塞。
   - **JIT／MMU 熱路徑實質提速**：
     - `core/mmu.c`：`ijc_clear` 僅清除實際使用過之分支表（依據 `ijc_tables_used` 位元遮罩），避免每次分支快取清除把上百 MB 未觸碰虛擬頁釘進實體 RAM。
     - `core/machine.c`：預設開啟 `HV_HOIST_CHECK=1`（迴圈反向跳轉單次測試）與 `HV_RANGE_DROP=128`（大範圍 TLBI 無鎖單次掃描失效）。
     - `host/vm.c`：`kicker_thread` 僅在次核心 `timer_due` 到期或 16 ms 後備檢查時才發起喚醒，停止每 1 ms 無意義打斷正在運作的次核心 JIT 鏈。
     - `EngineTuning.swift`：iOS 預設 `HV_WFI_SPIN=20`（低功耗 `ldaxr+wfe` 微秒級喚醒）與 `HV_SUPERBLOCKS=1`，大幅縮短 Mach IPC／視窗伺服器排程延遲。

## SideStore 安裝與覆蓋升級說明

- 本版維持 Bundle ID `com.henge.app`，**請勿刪除 iPad 上原有的 iPac**，以免遺失本機 macOS 虛擬機磁碟。
- 請在 SideStore 的 **My Apps** 分頁點選左上角 **`+`**，從 SideStore 本機 `Documents` 資料夾選取 `iPac-v0.6.1-build120.ipa` 進行覆蓋簽名安裝。
