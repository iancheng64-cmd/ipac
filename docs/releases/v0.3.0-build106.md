# iPac 0.3.0 / Build 106

日期：2026-11-24（台北）

這是既有 GitHub 發布版本，以下依原發布說明整理，本輪沒有重新建置或實機驗收此版。

## 這版改了什麼

- 支援本機、外接安裝後存回本機，以及完整隨身外接 SSD 模式。
- 支援本機與外接磁碟之間搬移 VM，並辨識 APFS / exFAT。
- 加入跨 iPad 的 RAM / CPU / 顯示設定適配。
- 提供外接磁碟安全退出，以及只清除已知 VM / 安裝資料的白名單操作。
- 主 App 顯示名稱改為 iPac，提供繁體中文介面，主 App 與 JIT helper 同步為 Build 106。

## 升級

維持 `com.henge.app` 和相同簽名 Team ID 直接覆蓋安裝。保留 `HengeJITHelper.appex`，並使用能保留 JIT 所需除錯權限的簽名方式。

不包含 Apple macOS 安裝映像或 Boot ROM。
