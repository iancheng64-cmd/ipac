# iPac 0.5.0 / Build 109

日期：2026-11-25（台北）

狀態：測試版。已加入下列來源改動；實機結果與建置結果須分別確認。

## 這版改了什麼

- **中英文介面切換**：加入繁體中文與英文選擇、字串目錄及切換範圍，涵蓋設定、安裝、JIT、單機設定與工作階段。
- **實體 RAM 偵測與自訂配額**：顯示裝置實體記憶體及可用狀態，允許將 VM 設定值調到實體 RAM 總量，不強制扣除安全預算；高風險設定仍顯示警示。設定值不代表 iPadOS 一定允許成功分配。
- **緊湊 JIT 中繼資料選項**：以較小的 offset 儲存三張 JIT pointer 表，減少這部分的中繼資料佔用。不是壓縮可執行 JIT 程式碼，也不代表整個 JIT 或 App 記憶體減半；不能保證所有工作負載都零效能影響。
- **安裝映像與下載驗證**：增加 IPSW 結構與恢復映像驗證、續傳回應檢查及錯誤處理。
- **外接儲存與 VM 設定安全**：加強路徑、外接目標、清理範圍、跨裝置記憶體設定及 manifest 檢查。
- **MoreRam 流程修正**：改善取消、非同步狀態世代及目標 App ID 的防護，避免過時操作覆蓋目前狀態。
- **版本化 IPA 輸出**：後續打包預設放到 `~/Downloads/iPac-Releases/v版本-build編號/`，附上此版本說明。

## 同步提供的手機 SSD 工具

- Android Magisk 模組 `ipac-phone-ssd` 0.2.0：在核心已支援 USB gadget mass-storage 的前提下，匯出獨立 GPT/APFS 磁碟映像。
- Mac APFS 映像建立工具：只建立新的獨立映像，不格式化手機正在使用的分割區。
- iPhone 7 / iOS 15 唯讀診斷工具：不啟動 SSH，不是 USB SSD 驅動。

這些是獨立工具，不會安裝在 iPad 的 IPA 內。Note 10 的實際型號、核心、root 狀態，以及手機至 iPad 的 USB 相容性仍待確認。

## 驗證與限制

- 本輪 13 組核心及 App 回歸目標全部通過，最終退出碼為 0；其中 JIT 中繼資料有 454 項檢查、0 個失敗。版本顯示更新後，雙語及語系呈現測試也再次通過。
- 版本化打包路徑、自訂輸出與無副作用查詢有 8 項回歸通過。這些測試不等於 iPad 真機驗收。
- 手機工具先前已通過 38 項映像建立測試、51 項 Android 測試及 24 項 iPhone 診斷檢查；另有 9 項獨立 Android 聚焦回歸通過。
- Mac 的可丟棄 APFS 映像通過檔案系統檢查、讀寫及卸離後唯讀重掛載。1 GiB 映像的 `diskutil verifyDisk` 因容量太小拒絕，不能算成通過。
- iPac 既有快速 flush 路徑及 pause 丟棄 flush 結果的寫入持久性風險尚未在本版修復。
- 手機 SSD 的實際掛載、速度、鎖屏、重接、VM 開機與快照恢復尚未驗收。先用可丟棄的 VM 測試，不要搬移唯一的重要資料。
- 效能情境、完整集中式 SSD 開機預檢等內容目前屬於提案，不列為已完成。

## 安裝

檔名：`iPac-v0.5.0-build109.ipa`

Bundle ID 維持 `com.henge.app`。使用相同簽名 Team ID 覆蓋安裝，保留 `HengeJITHelper.appex` 及所需的除錯權限。不要先刪除原 App。

本包不含 Apple macOS 安裝映像或 Boot ROM。發布附件的 SHA-256 另列於 `SHA256SUMS`。
