# iPac 0.4.1 / Build 108

日期：2026-11-25（台北）

這是既有 GitHub 發布版本，以下依原發布說明整理，本輪沒有重新建置或實機驗收此版。

## 這版改了什麼

- 啟動時自動檢查記憶體權限，整合 GetMoreRam / iRAM+ 申請流程。
- 加入 SideStore / AltStore 的 Refresh 跳轉；權限是否生效仍取決於簽名描述檔及裝置支援。
- 修正 Anisette 網址、逾時、WebSocket 接收上限、JSON 型別及 SideStore 帳號欄位處理。
- 改善 App ID 清單中的記憶體權限辨識、2FA 空值與取消流程。
- 修正 RAM / CPU 有效範圍、工作階段重試及小數容量顯示。
