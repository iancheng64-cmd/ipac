# iPac 0.5.6 / Build 115

日期：2026-11-28（台北）。從 Android 版移植 Sill 膠囊控制列、內建 Sill macOS 視覺鍵盤與雙模式觸控手勢，並針對顯示呈現、Metal 物件查找與輪詢熱路徑進行最佳化。

## 新增功能與順暢度最佳化

| 項目 | 說明與驗證 |
| --- | --- |
| 膠囊浮動控制列與 5 秒自動隱藏 | 支援隱藏／顯示控制列、5 秒無操作自動收起與頂端置中微調控制條（輕觸展開）、操作提示膠囊吐司通知（2.6 秒自動淡出），並新增「Sill 觸控模式」一鍵切換鈕。直立與全螢幕橫向模式共用一致狀態管理。 |
| 內建 Sill 視覺 macOS 鍵盤 | 移植 Android 版 5 列標準 QWERTY + 獨立方向鍵叢集，支援按住連發、Caps Lock LED 狀態燈、黏滯修飾鍵（⌃ / ⌥ / ⌘ / ⇧ 於下一鍵放開後自動釋放）與頂部 Sill 快捷膠囊列（`Esc`、`Spotlight`、`Mission`、`◂ Space`、`Space ▸`、`⌘C`、`⌘V`、`⌘Z`、`⌘W`、`⌘Q`）；右上角可一鍵切換 iOS 系統中／英輸入法（附回到 Sill 按鈕）或收起。 |
| Sill 雙模式觸控手勢與四指切換 | 支援「Sill 多指觸控板（Magic Trackpad 2 原生兩指捲動／縮放與三指切換桌面）」與「直接觸控指標（單指相對移動、輕點左鍵、按住 0.4 秒拖曳、兩指捲動與雙指右鍵）」即時切換；任一模式下**四指快速輕點螢幕**皆可顯示／隱藏控制列而不誤觸客體滑鼠點擊。 |
| 顯示與游標渲染最佳化 | `BootDisplay` 於 `gpuLive` 且亮度為 100% 時啟用 `CAMetalLayer.isOpaque = true` 直通合成；`pvg_metal.m` 以 `_Atomic` 快取游標縮放與銳利邊緣設定，消除每幀讀取 `NSUserDefaults` 鎖定與 ObjC 訊息開銷。 |
| Metal 物件查詢與輸入輪詢加速 | 新增 `HvTaskObjectTable` 平面索引表（最高 8,192 筆直接陣列存取＋溢位字典後備），消除繪圖熱路徑上每次 `NSNumber` 裝箱與 `NSDictionary` 雜湊；`exec:` 單次批次重複利用已解析的 `HvObject *` 與快取環境旗標；1 kHz `xhci`／`virtio-input`／`net_slirp` 閒置輪詢改用無鎖原子頭尾檢查，雙向捲動合併為單次喚醒。 |

## Mac 端驗證與實機狀態

- **待實機確認**：iPad 實機啟動 macOS 的實際 FPS、體感流暢度、與多指手勢觸感尚未於本次 Mac 端測試執行。

## 升級與 SideStore 安裝提醒

- 維持相同 Bundle ID `com.henge.app` 與 Team ID 覆蓋安裝即可保留本機 64 GB 虛擬機與設定；**請勿先刪除 iPad 上的舊版 iPac**。
- 使用 SideStore 更新安裝時若出現延伸模組選項，請選擇 **Keep App Extensions** 以保留內建 StikJIT（`HengeJITHelper.appex`）。
