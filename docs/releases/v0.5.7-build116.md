# iPac v0.5.7 (Build 116)

## 主要更新

1. **恢復 Henge 原版膠囊控制列與呼叫方式**
   - 移除 5 秒自動隱藏倒數、頂端置中微調條、膠囊切換按鈕與自動跳出的 toast 提示。
   - 還原原本 6 鍵膠囊控制列（隱藏、鍵盤、貼上、放大、資訊、關機）與「四指同時輕點螢幕即可顯示控制列」提示。
   - 控制列中的「鍵盤」按鈕直接開啟／收起內建 macOS 視覺鍵盤，並可在鍵盤頂端工具列隨時切換系統中／英輸入法。

2. **Apple 風格 macOS 視覺鍵盤（`SillVirtualKeyboardView`）**
   - 採用 iPadOS Dark Magic Keyboard 與 Liquid Glass 毛玻璃語彙重新設計：半透明 `deskGlass` 底座搭配 `24pt` 連續圓角與細緻內外高光框線（支援系統「減少透明度」與「減少動態效果」無障礙設定）。
   - 鍵帽採用深色層次漸層、上緣細高光與按壓微縮／即時震動回饋；`Return` 鍵使用 Apple 系統藍，啟動中的 `Shift` / 修飾鍵反白顯示，`Caps Lock` 保留綠色 LED 指示燈。
   - 以 Apple SF Symbols 呈現刪除、Tab、Shift、Caps Lock、Control、Option、Command、Return 與倒 T 方向鍵，搭配系統中／英切換（`globe`）與收起鍵盤（`keyboard.chevron.compact.down`）圖示。

3. **保留 Build 115 虛擬機順暢度優化與 Sill 多指觸控手勢**
   - 保留 `Trackpad` 的 Sill 多指觸控模式（可於 App 設定切換）與 Metal / 直通顯示 / xHCI 輸入輪詢最佳化。

## SideStore 安裝與覆蓋升級說明

- 本版維持 Bundle ID `com.henge.app`，**請勿刪除 iPad 上原有的 iPac**，以免遺失本機 macOS 虛擬機磁碟。
- 若使用 SideStore 安裝本機 `.ipa`，請在 SideStore 的 **My Apps** 分頁點選左上角 **`+`**，從 SideStore 本機 `Documents` 資料夾選取 `iPac-v0.5.7-build116.ipa` 進行覆蓋簽名安裝。
