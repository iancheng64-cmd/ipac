# iPac v0.5.9 (Build 118)

## 主要更新

1. **四指輕點／四指長按皆可切換顯示與隱藏控制列**
   - 保留 Henge 原版頂部膠囊控制列外觀與雙模式分段切換鈕。
   - 不論是在多指觸控板模式還是手勢觸控模式，**四指輕點**與**四指長按**都能直接顯示或隱藏控制列，並在隱藏時自動收起視覺鍵盤。

2. **觸控板模式加入 Mac 原生「三指拖曳」**
   - 啟用三根手指拖曳視窗、檔案或選取文字時自動按住左鍵跟隨移動，放開手指即完成放置（不誤觸 Mission Control）。
   - 保留單指移動／輕點左鍵、單指長按拖曳、兩指捲動／縮放／輕點右鍵等原生 Magic Trackpad 2 體驗。

3. **手勢觸控模式對齊 Sill 全螢幕互動體驗**
   - 新增 USB xHCI Port 3 獨立絕對座標指標裝置（`iPac Touch Pointer`），自動對齊實機螢幕裁切範圍：
     - **單指輕點**：直接精準點擊手指所在 macOS 座標。
     - **單指長按（不移動）**：開啟右鍵選單。
     - **單指長按後移動**：按住左鍵一對一拖曳（視窗、滑桿、選取文字）。
     - **單指／雙指滑動**：透過 Magic Trackpad 2 兩指觸控合成滑順像素級捲動。
     - **雙指輕點**：於雙指中點右鍵點擊。

## SideStore 安裝與覆蓋升級說明

- 本版維持 Bundle ID `com.henge.app`，**請勿刪除 iPad 上原有的 iPac**，以免遺失本機 macOS 虛擬機磁碟。
- 請在 SideStore 的 **My Apps** 分頁點選左上角 **`+`**，從 SideStore 本機 `Documents` 資料夾選取 `iPac-v0.5.9-build118.ipa` 進行覆蓋簽名安裝。
