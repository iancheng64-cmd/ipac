# iPac v0.5.8 (Build 117)

## 主要更新

1. **原版膠囊控制列加入 Sill 觸控板／手勢觸控雙模式切換鈕**
   - 維持 Henge 最原始頂部膠囊控制列外觀與呼叫方式：不會自動隱藏、不加頂端微調橫條或跳出 toast，隱藏後隨時**四指同時輕點螢幕**即可顯示控制列。
   - 在膠囊控制列內新增清晰兩段式模式切換鈕：
     - **Sill 多指觸控板模式**（觸控板圖示）：模擬 Apple Magic Trackpad 2 原生兩指捲動／雙指捏合縮放與三指切換桌面。
     - **手勢觸控指標模式**（手勢點選圖示）：單指拖曳移動游標、輕點左鍵、雙指輕點右鍵、長按拖曳視窗與雙指上下左右捲動。

2. **保留 Apple 風格虛擬鍵盤與虛擬機效能最佳化**
   - 保留 Build 116 的 iPadOS Magic Keyboard ＋ 毛玻璃質感 5 列 macOS 視覺鍵盤與 `中/英 IME` 切換。
   - 保留 Build 115 的直通顯示、Metal 物件查找與 xHCI / virtio 輸入輪詢順暢度最佳化。

## SideStore 安裝與覆蓋升級說明

- 本版維持 Bundle ID `com.henge.app`，**請勿刪除 iPad 上原有的 iPac**，以免遺失本機 macOS 虛擬機磁碟。
- 請在 SideStore 的 **My Apps** 分頁點選左上角 **`+`**，從 SideStore 本機 `Documents` 資料夾選取 `iPac-v0.5.8-build117.ipa` 直接覆蓋簽名安裝。
